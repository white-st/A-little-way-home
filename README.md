# 探索新道路

**A Little Way Home** 是一款旋转道路、帮助动物回家的微信小游戏。当前源码版本为 **0.9.17**，使用 JavaScript 与 Canvas，提供同源浏览器预览。

- 闯关模式：140 关，棋盘从 3×3 到 9×9，逐关解锁。
- 经典模式：5×5 到 9×9 随机可解棋盘，支持限步挑战与休闲模式。
- 支持星级、签到、体力、钻石、本机纪录、音乐音效与黑夜模式。
- 微信开发版与体验版具有无限体力和钻石；正式版按正常规则消耗。

## 快速开始

需要 Node.js 18 或更新版本；没有第三方运行依赖，无需安装依赖。

```sh
npm start
```

浏览器打开 <http://127.0.0.1:4173/>。微信开发者工具导入仓库根目录，项目类型为小游戏，发布入口由 `project.config.json` 指向 `minigame/`。其他开发者需使用自己有权限的微信 AppID。

```sh
npm run build:wechat
npm test
```

`miniprogram/core/` 与 `miniprogram/assets/audio/` 是共享逻辑、素材的源文件；`minigame/core/` 与 `minigame/assets/audio/` 由构建脚本同步，请勿单独修改生成副本。小游戏界面和交互在 `minigame/src/`，浏览器预览在 `preview/`，检查在 `tests/`。

本仓库包含源码、素材、生成副本、预览和检查。历史截图、微信预览二维码、交付压缩包和本地备份位于 `artifacts/`，保留在开发电脑，不上传 GitHub；微信个人配置、日志和本地环境文件也不纳入版本管理。下方历史记录中的本机路径和截图引用仅用于开发追溯，旧版本功能以最新记录和当前源码为准。

## 当前玩法

- 棋盘每格是一块可旋转道路，包括动物出发的终端、直路、弯路和三向岔路，没有四向十字。每格点击顺时针旋转 90°，中央小屋所在格也可旋转。
- 相邻道路接口相对才能连接，通向中央小屋的道路微微亮起；无跨格行走或边界穿越。全部道路接通且没有断口后，终端上的小猫、兔子、狐狸或小熊同时沿实际路线回家；行走中道路锁定，离开页面暂停，返回继续，也可免费重玩。
- 全部动物到家后显示“恭喜你过关了”彩蛋及金色五角星，按左、右、中顺序弹性入位并轻微过冲回弹；前景彩带避开文字持续向四周散开，直到离开弹窗。归家动画不重复发放奖励或播放完成音。成绩与奖励在接通时保存，退出应用不会丢失已完成结果。
- 闯关模式共 140 个固定关卡，3×3 至 9×9 七种尺寸，每种 20 关。每种尺寸的第 1 关直接开放，通过后解锁该尺寸下一关，已完成关卡可重玩。选关每页 4 关，5 页可浏览全部关卡。进度和每关最佳星数保存在本机。
- 经典模式任选 3×3 至 9×9，实时生成新的可解棋盘，没有四向十字。重玩恢复同一局初始棋盘，生成下一局消耗 1 点体力。成绩与闯关进度隔离。
- 支持撤销、当前关重置、逐步提示。提示标出具体行列及需旋转次数，连续点击时倒计数，不自动替玩家旋转。提示引导到一条经过验证的参考解；其他正确解同样可以通关，不承诺提示为最少操作解。
- 无提示且旋转步数不超过参考目标获 3 颗星；不超过目标加二获 2 颗星；其余 1 颗星。首页汇总闯关各关最佳成绩，重复挑战同分或低分不累加，提升成绩只增加差额。撤销恢复步数，重置清除本局步数与提示次数；通关后锁定棋盘。
- 线路以约 260 毫秒缓出动画旋转，连续点击可顺滑衔接，撤销反向转回。新接通节点出现扩散光圈，终端伴随细小光点；持续亮着不会重复触发。浏览器尊重减少动态效果设置。
- “重置”只重置当前关；“重新开始本模式”有确认步骤，只清空当前尺寸进度，保留其他尺寸、声音偏好和本机档案，不重置已领钻石账目。
- 大厅提供体力与钻石、签到、主题和个人纪录。具体奖励与恢复规则见文首 0.7.0 记录；个人纪录按模式和尺寸记录最高星级、同星级最少步数，仅本机保存，不是好友排行榜。

## 音乐与音效

- 旋转、接通新节点和通关使用三种不同的原创音效；一次接通多个节点只播放一次接通音。
- 背景音乐是一段 25.6 秒的原创轻柔循环。首次有效操作或手动打开音乐后播放，切关和重置不重头播放；关闭或切后台暂停，恢复后续播。
- 两个独立开关、两个 0–100% 的音量滑块；默认音乐 28%、音效 65%。音量即时应用到已存在和之后创建的播放器，不重启音乐、不改变开关、不影响另一个通道。
- 0% 是有效的音量设置。关闭某一通道后仍可预设音量，重新开启使用该数值。音量与开关分别保存，刷新/重新打开恢复，重新闯关也不清除。
- 设置读取失败会提示：音量使用默认值，开关读取失败时暂时关闭对应通道。保存失败仍保留当次调整，提示无法持久保存。播放失败不影响游戏。
- 音效使用最多四个播放器（两个短促旋转声、接通声、通关声各一）；静音、切关、重置、切后台等状态停止音效。音乐独立使用一个循环播放器。微信页面卸载销毁全部播放器，遵循系统默认静音规则，不使用后台音乐服务。
